# 핸드드립 카페

밀려오는 주문 속에서 핸드드립 커피를 정확하게 내리는 카페 타이쿤. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나.

## 한 잔의 순서
- **핫**: 원두 계량 → 분쇄 → 물 온도 → 린싱 → 푸어 4번 → 서빙
- **아이스**: 원두 계량 → 분쇄 → 물 온도 → 린싱 → 얼음 계량 → 푸어 4번 → 저어주기 → 서빙

## 혼란 요소
- 손님이 계속 들어오고, 참을성이 다하면 떠난다 (하트 3개)
- 주전자는 모든 자리가 같이 쓴다. 뜸 들이는 동안 식으니, 다른 주문을 만지다 보면 온도가 어긋난다
- 3일차부터 손님이 가끔 주문을 바꾼다 (핫 ↔ 아이스). 값이 달라지는 단계부터 다시 해야 한다
- 날이 갈수록 메뉴(7종)와 자리(1 → 2 → 3개)가 늘어난다

## 레시피 (참고)
- 핫: 원두 20g · 물 300g · 92°C (테츠 카스야 4:6 방식의 분량), 첫 푸어는 원두의 2배로 뜸 들이기
- 아이스: 일본식 급랭 — 원두 20g · 뜨거운 물 200g · 94°C, 서버에 얼음 100g을 먼저 담고 그 위로 내린다
- 라이트/다크 로스트, 라지 사이즈는 같은 비율(1:15, 아이스는 1:10 + 얼음)로 온도·분쇄만 달리했다
- 뜸 들이는 시간은 게임에서 짧게(5초·4초) 줄였다

`index.html` 을 그대로 열면 된다. 규칙은 `logic.js`, 화면·입력은 `game.js`.
